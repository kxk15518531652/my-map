maptest05 · 华东理工大学徐汇校区校园电子地图

打开方式：
解压 maptest05.zip，然后双击 maptest05 文件夹里的 index.html。无需联网。

新增：
1. 首次打开有一张全屏欢迎页，底图是原校园地图，CSS 只模糊背景，不模糊文字。
2. 点击「进入校园 · 开启音乐」按钮才开始播放背景音乐，正常解决大多数浏览器禁止无交互有声自动播放的问题。
3. 欢迎页淡出后，地图云雾散开；随后可使用原有的两个建筑热区。

保留功能：
一食堂与和平楼的精确热区、悬浮高亮、点击音效、详情页、2秒轮播、点击当前照片查看大图、背景音乐开关。

如何修改：
- 关闭进入地图后的云雾：打开 script.js，改为 const ENABLE_CLOUD_INTRO = false;
- 调整欢迎页地图模糊：打开 style.css，查找 .welcome-screen__background，修改 blur(9px)。
- 调整欢迎页标题和按钮文字：打开 index.html，查找「网页欢迎页 HTML」。
- 修改背景音乐音量：打开 script.js，找到 campusMusic.volume = 0.42; 可修改 0~1。

说明：网页代码无法无条件绕过浏览器的有声自动播放限制；「进入校园」按钮是符合浏览器策略的播放触发方式。
